# Private International Counsel — лендинг

Одностраничный лендинг личного бренда международного юридического советника
и траблшутера. Без сборки и зависимостей: чистые HTML, CSS и JavaScript.

## Файлы

| Файл         | Что внутри                                                        |
|--------------|-------------------------------------------------------------------|
| `index.html` | Разметка всех секций + встроенный SVG-спрайт иконок               |
| `styles.css` | Дизайн-система: цветовые токены, типографика, сетка, адаптив      |
| `script.js`  | Табы практик, модальные окна, калькулятор рисков, форма, canvas   |
| `README.md`  | Этот файл                                                          |

Папок нет — все файлы лежат в корне, репозиторий можно залить как есть.

## Локальный просмотр

Проще всего в VS Code:

1. Открыть папку: `File → Open Folder…`
2. Поставить расширение **Live Server** (Ritwick Dey).
3. Правый клик по `index.html` → **Open with Live Server**.

Или через любой локальный сервер:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Можно просто открыть `index.html` двойным кликом — всё будет работать,
кроме копирования контактов в буфер обмена (браузеры разрешают
`navigator.clipboard` только по `http://` или `https://`).

## Публикация на GitHub Pages

1. Создать репозиторий на GitHub.
2. Загрузить `index.html`, `styles.css`, `script.js`, `README.md` в корень
   (кнопка **Add file → Upload files**) либо через git:

```bash
git init
git add .
git commit -m "Landing page"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

3. `Settings → Pages → Source: Deploy from a branch → main / (root)` → **Save**.
4. Через минуту сайт будет доступен по `https://USERNAME.github.io/REPO/`.

Свой домен подключается там же: `Settings → Pages → Custom domain`.

## Что нужно заменить перед публикацией

Всё, что стоит в квадратных скобках, — плейсхолдеры.

**`index.html`**

- `[ИМЯ ФАМИЛИЯ]` — в шапке и в футере — 5 мест (строки 6, 11, 54, 313, 333).
- `<title>` и `og:title` в `<head>`.
- Контакты в секции «Защищённая линия связи»: `[+00 000 000 00 00]`,
  `[@username]`, `[FINGERPRINT]`.
- Те же контакты продублированы в модальном окне `id="ov-secure"` внизу файла.
- Портрет: блок `.plate` в hero. Заменить `<div class="plate-note">…</div>`
  на `<img src="portrait.jpg" alt="…">` (пропорции 4:5). Файл кладётся рядом,
  в корень, — папка не нужна.
- Метрики Trust Bar (`$1.5B+`, `100%`, `25+`, `24/7`) — блок `.trust-grid`.

**`script.js`**

- `PRACTICES` (строка 65) — четыре практики: название, лид, услуги,
  боковая колонка. Формат услуги: `["Заголовок", "Описание"]`.
- `RISKS` (строка 166) и `JURS` (строка 200) — данные калькулятора рисков.
  Поле `w` — вес для расчёта уровня угрозы: сумма весов риска и юрисдикции
  ≥ 5 даёт «Критический», 4 — «Высокий», меньше — «Повышенный».

**`styles.css`**

- Палитра и шрифты — в блоке `:root` в самом верху файла. Все цвета вынесены
  в семантические токены (`--bg`, `--surface`, `--ink`, `--gold`…),
  захардкоженных значений в правилах нет — тему можно перекрасить целиком,
  правя только `:root`.

## Светлая и тёмная тема

По умолчанию сайт светлый. Тёмная версия лежит в том же файле и включается
одним атрибутом в `index.html`:

```html
<html lang="ru" data-theme="dark">
```

Не забудьте заодно поменять `<meta name="theme-color">` на `#0B0D10` —
это цвет строки браузера на мобильных.

Акцент в светлой теме разведён на три роли, потому что одно золото
`#C5A880` на белом даёт контраст 2:1 и не читается:

| Токен           | Значение  | Где применяется               |
|-----------------|-----------|-------------------------------|
| `--gold`        | `#7A5C31` | текст и иконки — 5.4:1        |
| `--gold-solid`  | `#8A6A3B` | заливка кнопок, белый текст   |
| `--gold-line`   | `#C2A57A` | волосяные линии и декор       |

Футер намеренно остался тёмным (`#16181C`) в обеих темах — он локально
переопределяет токены и работает как якорь внизу страницы.

## Форма обратной связи

Форма демонстрационная: данные никуда не отправляются, обработчик в
`script.js` просто показывает экран подтверждения. Для реальной отправки
подключите сторонний сервис (Formspree, Getform, Web3Forms) — GitHub Pages
раздаёт только статику и не умеет обрабатывать POST-запросы.

## Юридическая проверка перед запуском

Метрики в Trust Bar взяты как образец. Формулировка «100 % кейсов»
в ряде юрисдикций (Великобритания, часть стран ЕС и штатов США)
может трактоваться как гарантия исхода дела, что запрещено правилами
адвокатской рекламы. Перед публикацией показатели стоит подтвердить
или переформулировать нейтрально.

Дисклеймер об адвокатской тайне и отсутствии публичной оферты — в футере.
