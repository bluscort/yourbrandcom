# Mark Romanov — Private International Practice

Двуязычный (EN/RU) одностраничный сайт личного бренда международного юриста,
юрисконсульта и арбитра. Без сборки, без зависимостей, без папок — чистые
HTML, CSS и JavaScript, готовые к заливке в корень репозитория.

## Файлы

| Файл          | Вес    | Что внутри                                                      |
|---------------|--------|------------------------------------------------------------------|
| `index.html`  | 30 КБ  | Разметка всех секций, SVG-спрайт иконок, JSON-LD, OG-метатеги    |
| `styles.css`  | 21 КБ  | Обсидиан и золото: токены, типографика, сетки, адаптив           |
| `script.js`   | 35 КБ  | Словарь EN/RU, переключение языка, модалки, форма, анимации      |
| `crest.png`   | 112 КБ | Герб с альфа-каналом, 560×623 — используется на всём сайте       |
| `favicon.png` | 16 КБ  | Иконка вкладки 180×180, из того же герба                         |
| `logo.png`    | 1.2 МБ | **Исходник.** Сайтом не используется, в репозиторий можно не класть |

Итого рабочий сайт весит 214 КБ.

## Локальный просмотр

В VS Code: расширение **Live Server** → правый клик по `index.html` →
**Open with Live Server**.

Или любым сервером:

```bash
python3 -m http.server 8000     # затем http://localhost:8000
```

Открывать `index.html` двойным кликом можно, но кнопки «Копировать» в
пресс-модалке не сработают: браузеры дают доступ к буферу обмена только
по `http://` и `https://`.

## Публикация на GitHub Pages

1. Создать репозиторий, загрузить файлы в корень (`Add file → Upload files`)
   или через git:

```bash
git init
git add .
git commit -m "Mark Romanov — personal brand site"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

2. `Settings → Pages → Deploy from a branch → main / (root)` → **Save**.
3. Сайт поднимется на `https://USERNAME.github.io/REPO/`.
   Свой домен — там же, `Custom domain`.

## Что заменить перед запуском

### Контакты

Всё в квадратных скобках — заглушки. Встречаются в трёх местах `index.html`:
секция контактов, футер, модалка пресс-кита.

```
[+00 000 000 00 00]        Signal
[name@proton.me]           Proton Mail
[@username]                Telegram
[press@markromanov.com]    пресс-служба
```

В модалке пресс-кита те же значения продублированы в атрибутах
`data-copy="…"` — их нужно поменять вместе с видимым текстом, иначе кнопка
скопирует старое.

### Домен

В `<head>` прописан `markromanov.com` — поменяйте на реальный в четырёх
местах: `<link rel="canonical">`, `og:image`, `twitter:image`, `"url"` внутри
JSON-LD.

### Портрет

В секции «Биография» (`<section id="biography">`) оставлено место под фото —
рамка `.photo-slot` с пропорцией 4:5. Прямо над ней в `index.html` лежит
комментарий с готовой строкой: положите файл рядом с `index.html` и замените
весь блок `<div class="photo-slot">…</div>` на

```html
<img src="portrait.jpg" alt="Mark Romanov" width="880" height="1100" loading="lazy" decoding="async">
```

Оптимальный исходник — вертикальный портрет от 880×1100 px. Кадрирование
задаётся в `styles.css`: `.bio-fig img{object-position:50% 22%}` — процент по
вертикали двигает лицо в кадре. На широком экране фото залипает при прокрутке
(`position:sticky`), на ширине до 1080 px секция складывается в одну колонку.

### Тексты

Все строки живут в объекте `I18N` в начале `script.js` — два блока, `en` и
`ru`, с одинаковым набором ключей. HTML содержит английский вариант как
исходный (это то, что видят поисковики), а JS подменяет его при переключении.

Меняя текст, правьте **и разметку, и словарь** — иначе после первого
переключения языка вернётся старая версия.

Чтобы добавить третий язык, скопируйте блок `ru`, переведите значения и
добавьте кнопку в переключатель:

```html
<button type="button" class="lang-b" data-lang="de" aria-pressed="false">DE</button>
```

## Что здесь настоящее, а что — каркас

Секция «Биография» перед «Профилем» набрана присланным текстом дословно,
разбитым на четыре блока. Разбивка ничего не добавляет и не убирает: блок 1 —
первое предложение, блок 2 — про клиентов и поручения, блок 3 — про географию и
языки, блок 4 — про степень, членство в IBA и должности в инвестиционных
компаниях. Мною написаны только подписи блоков (`bio.k1`–`bio.k4` в
`script.js`: «Профиль практики», «Клиенты и поручения», «География и языки»,
«Квалификация и должности») — это рубрикация, а не факты. Если нужен сплошной
текст без подписей, удалите теги `<h3 class="bio-k">` из разметки.

Из этого же текста заполнены поля `description`, `memberOf` и `areaServed` в
JSON-LD в `<head>`.

Тексты пяти практик и биография взяты **дословно из присланного PDF** — и в
английской, и в русской версии. Совпадение проверено посимвольно.

Исправлены только орфографические опечатки исходника, ни одной формулировки
не тронуто. Полный список правок, чтобы вы могли откатить любую:

| Было (PDF)             | Стало                  | Где           |
|------------------------|------------------------|---------------|
| Интерпол-Уведомления   | Интерпол-уведомления   | Практика 2 RU |
| Корпоративная разведка | корпоративная разведка | Практика 5 RU |
| риск менеджмент        | риск-менеджмент        | Практика 5 RU |
| Индивидульные          | Индивидуальные         | Практика 5 RU |
| разноуровненвых        | разноуровневых         | Биография RU  |
| исскуства              | искусства              | Биография RU  |

Английский текст практики 4 в исходнике написан от первого лица во
множественном числе («We provide…», «We handle…», «We work with…»), тогда
как остальные четыре — безличные. Оставил как в PDF. Если захотите
выровнять тон, править нужно `pr4.b` в блоке `en` внутри `script.js`.

**Сверх присланного я ничего не добавлял.** Разделы «Медиа» и «Аналитика» —
это рубрики и темы, а не публикации: там нет названий изданий, дат, цитат и
ссылок на несуществующие материалы. Формулировки говорят «темы, по которым
ведётся анализ», а не «статья вышла там-то». Перед запуском их стоит
заменить реальными выступлениями и публикациями.

По той же причине на сайте нет счётчиков вроде «$1.5 млрд защищённых
активов» и «100 % выигранных дел»: в Великобритании, ряде стран ЕС и штатов
США подобные формулировки трактуются как гарантия исхода дела и нарушают
правила адвокатской рекламы.

Раздел «Профиль» — шесть блоков. Первые три (единая точка ответственности,
единый координационный центр, риски/активы/репутация) и лид секции собраны из
формулировок, присланных по итогам встречи, — правились только под единый тон.
Оставшиеся три (конфиденциальность, стратегия, дипломатия) и вводные фразы
секций написаны мной как связующий текст — это описание подхода, а не факты
биографии.

Биография и профиль намеренно разведены: биография (`#biography`) —
о личности и квалификации, профиль (`#about`) — о практике и роли для
клиента. В навигации это два разных пункта. Подпись первого блока биографии
поэтому называется «Области права», а не «Профиль практики» — чтобы слово
«профиль» не значило на сайте две разные вещи. Из проверяемых сведений на сайте заявлено
только то, что пришло от вас в тексте биографии: степень PhD, признанная в
Великобритании, и членство в International Bar Association. Допуски к
практике и членство в арбитражных институтах не заявлены — добавляйте их
только в том виде, в каком они подтверждаются документами.

## Форма обращения

Форма упрощена до трёх полей — имя, способ связи и необязательное описание
вопроса. Отдельные поля под юрисдикцию, организацию, выбор канала и чекбокс
NDA убраны: на первом контакте они отпугивают, а всё существенное всё равно
уточняется в ответном сообщении.

Защищённые каналы (Signal, Proton, Telegram) остались рядом с формой —
для тех, кто предпочитает написать напрямую, минуя её.

Форма проверяет заполнение обязательных полей и показывает экран
подтверждения, но **никуда не отправляет данные**. GitHub Pages раздаёт
только статику и не обрабатывает POST.

Для реальной отправки подключите Formspree, Getform или Web3Forms и
замените обработчик `form.addEventListener("submit", …)` в конце
`script.js` на настоящий `fetch`.

Отдельно взвесьте риск: если по форме пойдут чувствительные обращения,
любой внешний обработчик становится третьей стороной в переписке,
защищённой тайной. Практичнее оставить её точкой первого контакта, а
существо дела уводить в Signal или Proton — как и написано в тексте под
кнопкой.

## Технические детали

**Герб.** `crest.png` получен из вашего `logo.png`: убран чёрный фон
(альфа-канал восстановлен из яркости, цвет разделён на прозрачность, чтобы
на краях не было тёмной каймы), обрезаны поля, размер уменьшен до 560 px и
палитра квантована — 1.2 МБ превратились в 112 КБ без видимой потери
качества. Если понадобится пересобрать из другого исходника, нужны Pillow и
numpy.

**Шрифты.** Заголовки — Playfair Display, имя и логотип — Cinzel, текст —
Inter. У Cinzel нет кириллицы, поэтому в русской версии имя автоматически
набирается Playfair Display — правило `html[lang="ru"] .hero-name` в
`styles.css`. Это сделано намеренно, а не является ошибкой отрисовки.

**Язык по умолчанию.** При первом заходе определяется по языку браузера
(кириллические локали → RU, остальные → EN), затем выбор запоминается в
`localStorage` под ключом `mr-lang`.

**Доступность.** Скип-ссылка, семантические заголовки, `aria-label` на
интерактивных элементах, ловушка фокуса в модалках, закрытие по Escape,
видимый фокус, поддержка `prefers-reduced-motion`. Контраст текста проверен
по WCAG: основной 17.9:1, вторичный 9.3:1, подписи 5.2:1, золото 7.4–11:1 —
все пары проходят уровень AA для мелкого текста.

**SEO.** Заголовок и описание меняются вместе с языком, прописаны Open Graph
и Twitter Card, добавлена микроразметка JSON-LD `Person` с перечнем
компетенций и услуг.
